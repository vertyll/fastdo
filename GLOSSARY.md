# Glossary

Terms the documentation uses, the standard each one comes from, and where it is explained.

| Term                  | Meaning                                                                                  | Standard                                                                                                                                           | Explained in                                                                                                                  |
|-----------------------|------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------|
| BFF (token handler)   | The VEDS gateway signs the user in and keeps the tokens; this front-end never holds one. | —                                                                                                                                                  | [Authentication](docs/authentication.md)                                                                                      |
| Effective permissions | What the caller may do with one row, resolved by the owning service and sent with it.    | —                                                                                                                                                  | [Architecture: Permissions decide what renders](docs/architecture.md#permissions-decide-what-renders)                         |
| ETag, `If-Match`      | Version of a resource, and the condition a write carries so a stale edit is refused.     | [RFC 9110](https://www.rfc-editor.org/rfc/rfc9110#section-8.8.3) §8.8.3, [RFC 9110](https://www.rfc-editor.org/rfc/rfc9110#section-13.1.1) §13.1.1 | [Calling the VEDS API: Optimistic concurrency](docs/veds-api.md#optimistic-concurrency)                                       |
| File reference        | A file id the back-end stores, exchanged for a signed link when it is needed.            | —                                                                                                                                                  | [Calling the VEDS API: Files are references](docs/veds-api.md#files-are-references)                                           |
| ICU MessageFormat     | The message syntax, with plural rules for Polish.                                        | [ICU MessageFormat](https://unicode-org.github.io/icu/userguide/format_parse/messages/)                                                            | [Translations: ICU, single brace](docs/translations.md#icu-single-brace)                                                      |
| Message key           | A key the back-end sends instead of prose, rendered here from the translation catalog.   | —                                                                                                                                                  | [Translations: Two sources, one catalog](docs/translations.md#two-sources-one-catalog)                                        |
| Problem document      | The JSON body of every refusal from the VEDS API.                                        | [RFC 9457](https://www.rfc-editor.org/rfc/rfc9457)                                                                                                 | [Calling the VEDS API: A refusal is an RFC 9457 problem document](docs/veds-api.md#a-refusal-is-an-rfc-9457-problem-document) |
